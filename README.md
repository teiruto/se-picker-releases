# SEPicker — 音素材セレクター

Windows向けの個人制作ツールです。WAV素材の試聴・選別・タグ編集・波形調整をブラウザー画面から操作します。

- 制作物紹介：https://teiruto.pages.dev/works/se-picker/
- 操作ガイド：https://teiruto.pages.dev/works/se-picker/manual.html
- 配布ファイルはReleasesのSEPicker-portable.zipです。展開後、SEPicker.exeを起動してください。
- ZIPにはffmpeg・README・ffmpegのライセンス文書とソース入手先案内を含みます。音声素材は含みません。
- この配布版ではAI解析を無効にしています。
- アプリのスクリプト・README・元マニュアルはAI（GLM）を利用して作成されています。

このリポジトリは配布ファイル専用です。サイトコードや個人の音素材は公開しません。
